Step 2 — Choose your settings. Select your sand table model from the device dropdown, or enter custom dimensions. Adjust curve smoothness, fit mode, and padding to control how the pattern fills the sand bed. For raster images, you can also choose a trace mode (Outline, Threshold, or Centerline) and preview the traced paths before converting.

Step 3 — Convert and download. Click the Convert button. SandPath generates your .thr or .gcode file in seconds. Click Download to save it, then transfer it to your sand table using the manufacturer’s app or a USB drive.

How SandPath Works Under the Hood

SandPath is built differently from other sand table pattern tools. Instead of converting raster images into horizontal scanlines (which look unnatural in sand), SandPath uses proper vector-based conversion to produce continuous, flowing paths that look hand-drawn.

SVG Conversion

When you upload an SVG file, SandPath parses the actual path data from the SVG markup. It handles all standard SVG path commands including line segments, quadratic and cubic Bézier curves, elliptical arcs, and compound subpaths. Each curve is sampled into smooth point sequences, and the paths are reordered using nearest-neighbour sorting to minimise travel lines (the ugly straight lines between separate shapes). The result is a file where the ball moves in clean, continuous strokes with minimal visible transitions.

Image Tracing and Vectorisation

For raster images like photographs and PNGs, SandPath first converts the image into vector paths through a tracing process. Three tracing modes are available, each suited to different types of source material:

The Outline mode uses Sobel edge detection to find the boundaries and contours in a photograph or complex artwork. This produces a sketch-like result that captures the major features of the image without filling solid areas.

The Threshold mode applies a brightness cutoff to separate the image into black and white regions, then traces the boundaries between those regions using marching squares contour extraction. This works best for high-contrast images like logos, silhouettes, and text.

The Centerline mode skeletonises the image, reducing shapes to their thinnest possible single-pixel lines before tracing. This is ideal for line drawings, handwriting, and sketches where you want the ball to trace along the middle of each stroke rather than around its outline.

After tracing, the resulting vector paths go through Douglas-Peucker simplification to reduce point count while preserving shape accuracy. The simplified paths are then converted to your sand table’s native format just like an SVG would be.

Supported Sand Tables and Output Formats

SandPath supports the most popular kinetic sand tables on the market. Circular tables receive .thr files (theta-rho format, where each line contains a polar coordinate pair), and rectangular tables receive .gcode files (standard CNC G-code with G0/G1 linear moves in millimetre coordinates).

The supported devices are:

Oasis Mini by Grounded — a 6.5-inch circular table, one of the most popular entry-level sand tables. Uses .thr output with a maximum rho of 0.97.

Oasis One by Grounded — the larger 18.5-inch sibling. Also uses .thr output.

Sisyphus Mini — a 15.5-inch circular table by Sisyphus Industries. Uses .thr output.

Sisyphus Coffee Table — a 24.5-inch circular table built into a full-size coffee table. The largest Sisyphus model, using .thr output.

Sisyphus End Table — an 18-inch circular table in end-table form. Uses .thr output.

ZenXY by V1 Engineering — an open-source rectangular sand table that you build yourself. This is the only rectangular table in the lineup and outputs .gcode instead of .thr. Build sizes vary, so SandPath lets you enter custom width and height in millimetres.

Custom tables — if your table isn’t listed, you can select “Custom Circular” or “Custom Rectangular” and enter your table’s exact dimensions. SandPath will generate the appropriate output format for the shape you select.

Getting Started with Sand Table Art

Kinetic sand tables use a steel ball guided by magnets beneath a bed of fine sand to draw continuous patterns. The ball follows paths defined in theta-rho (.thr) or G-code (.gcode) files, tracing geometric designs, organic curves, and even converted photographs into the sand surface. The results are mesmerising — each pattern erases the last as the ball traces its new path through the sand.

What is a Theta-Rho (.thr) File?

Theta-rho is a polar coordinate format where each line contains an angle (theta, in radians) and a radius (rho, normalised from 0 to 1). The ball spirals outward and inward following these coordinates. This format is used by circular tables from Oasis (Grounded) and Sisyphus Industries. SandPath converts your SVG paths and traced images into this format automatically, handling coordinate transformation, path ordering, and boundary clipping so the ball never moves beyond the edge of the sand bed.

What is G-code?

G-code is the standard language for CNC (computer numerical control) machines and has been in use since the 1950s. Rectangular sand tables like the ZenXY by V1 Engineering use G-code with simple linear move commands: G0 for rapid travel (moving the ball without drawing) and G1 for drawing moves. Coordinates are specified in millimetres with absolute positioning. SandPath generates clean G-code with proper headers, metric unit declaration (G21), and absolute positioning mode (G90) so the file can be loaded directly without any manual editing.

Tips for Great Sand Art Patterns

The best sand table patterns use continuous, flowing paths with minimal lift-and-travel moves. When converting images, start with the Outline trace mode for photographs and switch to Threshold for high-contrast logos. The Path Detail slider controls simplification: coarser settings produce smaller files with smoother curves, while finer settings capture more detail at the cost of larger files and longer draw times. For SVG files, designs with single continuous strokes produce the cleanest results. Avoid very fine details smaller than the ball diameter (typically 10–15 mm on most tables) as they will not resolve clearly in the sand.

Frequently Asked Questions

Do I need to create an account? No. SandPath requires no sign-up, login, or payment. Upload a file, convert it, and download the result. The entire process takes seconds.

Are my files stored on the server? There is no server. All processing happens entirely in your browser using JavaScript. Your files are never uploaded anywhere — they stay on your device from upload to download.

Can I convert photographs? Yes. Upload any JPG, PNG, or WebP image and SandPath will trace it into vector paths using edge detection, thresholding, or centerline extraction before converting to your table’s format. You can preview the traced result before committing to a conversion.

What file types can I upload? SandPath accepts SVG vector files and raster images in JPG, JPEG, PNG, WebP, BMP, GIF, and TIFF formats. SVGs are converted directly from their path data. Raster images go through the tracing pipeline first.

My pattern has ugly straight lines between shapes. How do I fix this? These are travel lines — the path the ball takes between separate shapes. SandPath minimises these using nearest-neighbour path ordering. If they’re still visible, try using SVGs with fewer separate shapes, or increase the curve smoothness setting.

Can I use SandPath on my phone? Yes. SandPath is fully responsive and works on any device with a modern web browser, including phones and tablets. The upload area accepts files from your device’s file picker.
